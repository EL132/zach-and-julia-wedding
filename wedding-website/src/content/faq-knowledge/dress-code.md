# Dress Code

What’s the dress code? 
The wedding will be black tie; further details will be provided following the invitations. 

What’s the weather like? 
August in Skåne is lovely, expect temperatures of 20–25°C (68–77°F) with long, light-filled days. Sunset won't come until around 9:00–9:30 PM, giving evenings a magical golden quality. Pack a light layer for cooler nights.

What other clothes should we bring? 
We recommend packing some light jackets / shawls, as well as attire for the various activities available at Maryhill (pool / swimming in the sea, sauna, tennis / padel, hiking).
